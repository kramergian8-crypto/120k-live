# 120k-live

Live-Daten für [120k.ch](https://120k.ch) während des Laufs am 26.09.2026.

`live.json` wird während des Rennens alle 15 Sekunden vom Tracking-Gerät aktualisiert.
Die Website liest sie über jsDelivr.

**Dieses Repo ist absichtlich von der Website getrennt** — sonst würde jeder Schreibvorgang
einen Neubau der Website auslösen.
